Keeping images light

  • Shrink in the browser before upload: longest side 1600px, WebP. No server resizing.
  • One public bucket, one folder per persona: persona-id/image-id.webp.
  • Store width and height in the row so the grid lays out before images load.
  • Creators bring their own AI images. No generation inside the app yet.

Three tables

creatorsid, name, handle
personasid, creator_id, kind (character | brand), name, handle, bio, avatar, published
imagesid, persona_id, path, w, h, title, is_live, position

  • Teams: one creator per account
